1 · Persiapan (sekali saja)

1
Install ffmpeg — buka Command Prompt, jalankan: winget install Gyan.FFmpeg lalu tutup & buka lagi Command Prompt-nya.
2
Render video visualizer di halaman utama. Untuk live 24/7, resolusi 1280×720 / 30fps sudah sangat layak dan hemat bandwidth.
3
Ambil stream key tiap channel: YouTube Studio → Go Live → tab Stream → salin "Stream key". Satu channel = satu key. Jadwalkan/aktifkan siaran di YouTube Studio dulu supaya key-nya siap menerima.

2 · Daftar Siaran

Satu baris = satu channel YouTube yang siaran bersamaan. Data tersimpan hanya di browser ini (localStorage) — stream key tidak dikirim ke mana pun.

3 · Cek Bandwidth Upload

Tiap siaran memakan upload sebesar bitrate videonya (export 720p ≈ 4–5 Mbps, 1080p ≈ 10 Mbps). Isi kecepatan upload internetmu (tes di speedtest.net) untuk melihat aman/tidaknya.

4 · Download Script Siaran

Hasilnya satu file start-live.bat. Letakkan di folder yang sama dengan file video, lalu klik dua kali — semua siaran menyala di jendela terpisah, otomatis menyambung ulang kalau koneksi putus, dan video di-loop tanpa henti. Tutup jendelanya untuk menghentikan siaran.

Lihat isi script 
(daftar siaran masih kosong)
Video hasil export aplikasi ini sudah H.264 + AAC, jadi script memakai -c copy — tidak ada encoding ulang, CPU nyaris tidak terpakai, laptop biasa kuat menjalankan beberapa siaran sekaligus. Yang membatasi hanya kecepatan upload internet. PC harus tetap menyala selama siaran; kalau nanti mau 24/7 tanpa PC, script yang sama tinggal dijalankan di VPS.
